Kiki's Glam Studio - web files for GitHub Pages

Upload EVERYTHING in this folder (including the hidden ".nojekyll" file and the ".well-known" folder)
to the root of your GitHub repository, then turn on GitHub Pages (Settings > Pages > Deploy from branch > main / root).

Game:            https://YOUR-USERNAME.github.io/REPO-NAME/
Privacy policy:  https://YOUR-USERNAME.github.io/REPO-NAME/privacy.html

.well-known/assetlinks.json is a placeholder. Replace it with the file PWABuilder gives you.
Note: for Android to trust it, assetlinks.json must be at the ROOT of your domain
(https://YOUR-USERNAME.github.io/.well-known/assetlinks.json), so the easiest setup is a repository named
YOUR-USERNAME.github.io - see the publishing guide.
